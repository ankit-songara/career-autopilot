# Governance

career-autopilot is maintained by [@ankit-songara](https://github.com/ankit-songara), who has final say on scope, releases, and merges.

## How decisions are made

- **Small fixes** (bugs, docs, new portal providers): open a PR directly.
- **Features and behavior changes**: open an issue first so the approach can be discussed before you invest time.
- **Disagreements**: argued in the issue/PR thread; the maintainer decides.

## Upstream

This project extends [santifer/career-ops](https://github.com/santifer/career-ops). Changes to the shared pipeline core that would benefit everyone are best contributed upstream (see their `GOVERNANCE.md`); this repo carries the auto-apply engine and fork-specific behavior.

## Code of Conduct

Everyone participating is expected to follow the [Contributor Covenant](CODE_OF_CONDUCT.md).
