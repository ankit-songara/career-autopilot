# Support

## Where to ask

| I want to… | Go to |
|-----------|-------|
| Report a bug | [GitHub Issues](https://github.com/ankit-songara/career-autopilot/issues) |
| Ask a setup or usage question | [GitHub Issues](https://github.com/ankit-songara/career-autopilot/issues) (label it `question`) |
| Report a security vulnerability | [Private vulnerability reporting](https://github.com/ankit-songara/career-autopilot/security/advisories/new) — never a public issue |
| Ask about the upstream pipeline core | [santifer/career-ops](https://github.com/santifer/career-ops) discussions |

## Before opening an issue

1. Run `node doctor.mjs` — it diagnoses most setup problems.
2. Check [docs/SETUP.md](docs/SETUP.md) and [docs/FAQ.md](docs/FAQ.md).
3. Search existing issues.
